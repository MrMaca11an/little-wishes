# Little Wishes 2.0 — Soft Editorial

Дата исследования: 24 ноября 2026. Это собственная дизайн-система проекта, не копия внешних скиллов. Внешние рекомендации были изучены и применены вручную; сторонние CLI и axe не устанавливались.

## Направление
Личный дневник желаний, спокойная редакционная эстетика, минимум визуального шума. Фото реальных товаров — главный контент. Тёплый нейтральный фон, чистые белые поверхности, выразительная ягодная кнопка, мягкие акценты для коллекций. Не превращать сайт в корпоративный дашборд, не добавлять декоративные градиенты в каждую карточку.

## Токены

|---|---|
| Canvas | #FAF9F7 |
| Surface | #FFFFFF |
| Primary text | #302A2D |
| Secondary text | #6E6267 |
| Primary action | #93465E |
| Action hover / focus | #713249 |
| Blush surface | #F4E7EB |
| Sage surface | #E8EEE7 |
| Decorative border | #E6DFDF |
| Input boundary | #95878D |

Цвета текста и контролов проверяются по относительной яркости WCAG; основной текст на белом 14.05:1, вторичный 5.82:1, белый текст на ягодном 6.41:1. Тонкие декоративные границы не служат единственным сигналом состояния. Пастельные категории являются дополнительным визуальным кодом, названия остаются текстовыми. Приоритет и статус обозначаются словами, а не только цветом. Контрастность токенов не равна полному аудиту WCAG AA.

Типографика: локальные serif-гарнитуры Georgia / Charis SIL / Times New Roman для крупных заголовков и wordmark; системный sans для интерфейса. Без сетевой зависимости от шрифтов. Основной размер 15px, подписи 12–14px, заголовки fluid clamp. Цены — табличные цифры. Шкала отступов 4/8/12/16/24/32/48px. Радиусы 10/16/24px. Движение 150–180ms, без постоянных анимаций, отключается при prefers-reduced-motion.

## Компоненты и адаптивность
- Обзор: редакционный hero, импорт по ссылке до статистики, компактные коллекции, каталог.
- Каталог: карточки 230px и более на широком экране, 2 колонки на обычном телефоне, одна на очень узких экранах. Реальные фото object-fit: contain; демонстрационные товары используют собственные SVG-иллюстрации.
- Навигация: сайдбар на широких экранах; нижняя панель на телефоне; скрытые разделы в «Ещё».
- Формы: заметные границы, подписи, фокус, увеличенные зоны касания, нативный dialog, sticky действия, клавиатурная загрузка фото.
- Состояния: aria-current, aria-pressed, прогресс с доступным именем; видимый фокус; переход к содержимому; сохранение фокуса после изменения товара; пустой список и фильтры.

## Рекомендации и источники
- Anthropic Frontend Design: https://github.com/anthropics/skills/tree/main/skills/frontend-design — цельная эстетика, deliberate design tokens.
- Impeccable: https://github.com/pbakaus/impeccable — critique / audit / polish, сокращение визуального шума, реальное состояние интерфейса.
- UI/UX Pro Max: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill — палитра, типографика, согласованность и паттерны.
- Vercel Web Interface Guidelines: https://vercel.com/design/guidelines — клавиатура, формы, состояния, motion и touch.
- Google Modern Web Guidance: https://github.com/GoogleChrome/modern-web-guidance — современный CSS и доступность.
- Emil Kowalski: https://github.com/emilkowalski/skills — короткая осмысленная анимация, feedback.
- Apple HIG: https://developer.apple.com/design/human-interface-guidelines/ — иерархия и читаемость.
- WCAG 2.2: https://www.w3.org/TR/WCAG22/ — 4.5:1 обычный текст, 3:1 крупный текст и применимые нетекстовые элементы, минимальные интерактивные цели.
- Playwright axe guide: https://playwright.dev/docs/accessibility-testing — следующий шаг для автоматического полного сканирования доступности.

Для код-агента: при необходимости устанавливать внешние skills из официальных репозиториев после проверки кода и версии, например `npx skills add https://github.com/anthropics/skills --skill frontend-design`, `npx skills add https://github.com/pbakaus/impeccable --skill impeccable`, `npx skills add https://github.com/vercel-labs/agent-skills --skill web-design-guidelines`. Эти команды необязательны для работы сайта. Не внедрять внешние runtime зависимости только ради стиля.

## Проверки
`npm test` — 5 тестов импорта и 2 теста контраста. `python tests/ui-smoke.py` — добавление, импорт (mock), фильтр, покупка, коллекция, share (mock), мобильная ширина. `python tests/responsive.py` — семь страниц и два диалога при 320, 390, 768, 1024, 1440px, отсутствие горизонтального переполнения, Escape и доступное имя модального окна. Для Python-тестов нужны Playwright и Chromium (`/usr/bin/chromium` либо адаптировать путь). Полный аудит axe, реальные магазины, WebKit и продакшен Netlify не проверялись.
