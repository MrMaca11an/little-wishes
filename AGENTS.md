# kukla's wishes — правила для Codex / Claude Code

Прочитай README.md и DESIGN.md до изменения UI. Сохраняй Soft Editorial: спокойный фон, белые поверхности, глубокая ягодная кнопка, выразительный serif только в крупных заголовках, системный sans для контента. Используй существующие токены CSS. Не добавляй избыточные карточки, градиенты, тени, шрифты из CDN и непрерывные анимации. Цена, фото и название важнее декора.

Сохраняй функциональность импорта, валют, коллекций, данных и обратную совместимость localStorage `little-wishes-v1`. Не меняй SSRF-защиту и CSP без проверки. Не обещай импорт с любого магазина. Не меняй формат резервных копий без миграции. Не добавляй тяжёлые библиотеки без конкретной причины.

На каждой UI-задаче: проверь 320–1440px, фокус клавиатуры, мобильные цели, пустые состояния, длинные русские строки, контраст текста >=4.5:1 и границы применимых элементов >=3:1. Фото товаров не обрезай. Тестируй `npm test`, `node --check public/app.js`, `python tests/ui-smoke.py`, `python tests/responsive.py`. Используй скриншоты реального браузера, сравни до/после. Не заявляй полное соответствие WCAG, если не выполнен полный аудит. Обновляй DESIGN.md при изменениях дизайн-системы.
